## ⚡ Daily Routine
 
```java
public class HarishSontakke implements QAEngineer {
 
    private final String motto = "Break it before users do 🔍";
 
    @Override
    public void dailyRoutine() {
        while (true) {
            TestCase tc = analyzeRequirements();
            List<Bug> bugs = executeTests(tc);
 
            for (Bug bug : bugs) {
                raiseDefect(bug, Priority.CRITICAL);
                collaborateWithDevs();
                verifyFix();
                runRegressionSuite(); // never skip regression
            }
 
            improveFramework();   // always be automating
            learnSomethingNew();  // always be growing
        }
    }
 
    private boolean bugsExist() {
        return true; // they ALWAYS exist 😄
    }
}
```
